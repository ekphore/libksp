# libksp

libksp is a library meant to handle the lexing, parsing/interpreting of the KSP programming language
commonly found in [Kontakt](https://en.wikipedia.org/wiki/Kontakt_(software)) instruments. 

See the [project's website](https://ekphore.github.io) for more information.
